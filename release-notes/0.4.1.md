Updates now download inside the app; Android's installer asks you to confirm.

- **Updates (Android):** Download and install fetches the new version in Reparc with a progress bar, checks that the file is exactly the published one, and opens Android's installer. Tap Update there. The first time, Android asks you to allow installs from Reparc.
- If the download fails, you can still download in the browser.
- iPhone still opens the release page.
