Safer set logging, a privacy policy, and the first Google Play build.

- **Typed weights are kept:** when a set ends on its timer, a weight or rep count you typed is saved, never cleared.
- **No accidental taps:** when Skip rest turns into Set done (or back), a tap in the first moment after the change is ignored, so one late tap can't tick the next set empty or skip your rest.
- **Privacy policy:** Me → Privacy now links to the full policy on our website.
- **Licence:** RepArc is now closed source. Me → Licenses keeps the notices for the fonts, icons, photos, and body model.
- **Google Play:** each release now also makes a Google Play version, which gets its updates from Play. This test version keeps its in-app updates.
