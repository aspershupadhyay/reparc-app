Updates that always get the newest version, and keep going when you leave the screen.

- **Newest version:** Download and install now checks for the latest release first, so you never get a version that is already out of date.
- **Keeps going:** the download no longer stops or restarts when you go back or switch tabs. Come back to App updates to see its progress.
- **Open installer again:** if you close Android's installer, tap Open installer. It uses the file already downloaded and checked, with no new download.
- **Opening:** the logo and RepArc name now sit in the exact middle of the screen.
