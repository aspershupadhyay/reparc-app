One plan for every workout, a guided workout with voice, and clearer set rows.

- **Plans:** roadmaps and plans are now one thing. A plan has one or more days. Follow one plan, and start any day of any plan at any time. Your old plans are copied over with their history. Make your own plan, or build one for your goal.
- **Guided workout:** tap Start set. The set timer, the rest, and the next set run on their own, and a voice (Charlie or Matilda) says when each starts and ends. Turn it off, or change the voice, in Me → Training.
- **Set times:** each set now has weight, reps, and time. Measured set and rest times are saved. "Same as last set" fills weight and reps in one tap.
- **Clearer screens:** done sets and done days are easier to see in light mode, and finished exercises fold up during a workout.
- **AI plans:** a plan from an AI app is saved as one plan with days, and you choose when to follow it.
- **Downloads:** builds now come from github.com/aspershupadhyay/reparc. The source code is private.
