Android dialogs and back, clearer colours and type, and fewer dead ends.

- **Android feels like Android:** confirmations use Android's own dialog, and swiping back shows the page underneath before you let go. iPhone is unchanged.
- **Protein is no longer red:** protein, chest, dinner, and main muscles use a pink tone. Red now means only an error or Delete.
- **Sharper text:** letter spacing follows each font's own design, Apple's on iPhone and Inter's on Android.
- **The keyboard closes:** tap any empty space to close it. iPhone's number pad has no Done key, so it could cover Save before.
- **Buttons instead of directions:** "Log weight", "Set targets", "Back up", and "Settings" open the right place, instead of text telling you where to go.
- **Calmer Me tab:** each row's second line shows its state, such as "Targets off" or "No backup file yet".
- **Less repetition:** Home shows Log food once, and Workout → Plan starts with "Choose a goal" and one line.
